# Castlevania App — cómo generar el APK
Opción A (sin instalar nada): sube esta carpeta a un repo de GitHub → pestaña Actions → "Build APK" → descarga `castlevania-apk` (app-debug.apk).
Opción B (Android Studio): `npm install && npx cap add android && npx cap sync && npx cap open android` → Build > Build APK.
Antes: edita tu correo y teléfono en www/index.html (sección Contrátame).
PDF: `python3 make_pdf.py "LINK_DE_TU_APK"`
